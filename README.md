# Min professionella portfolio

Detta är min personliga portfolio som jag har utvecklat under min utbildning till **systemutvecklare .NET**.

Jag heter Feroza Darwish och arbetar som bemanningsplanerare samtidigt som jag studerar systemutveckling. På webbplatsen presenterar jag mina kompetenser, erfarenheter och projekt.

## Tekniker

- HTML5
- CSS3
- JavaScript
- Git och GitHub
- GitHub Pages

## Funktioner

Webbplatsen innehåller fyra interaktiva JavaScript-funktioner:

1. **Mörkt och ljust tema** – besökaren kan växla mellan två färgteman.
2. **Projektfiltrering** – projekten kan filtreras efter C#/.NET och webbutveckling.
3. **Kontaktformulär** – kontrollerar inmatade uppgifter och visar en bekräftelse. Formuläret är en demonstration och skickar inga riktiga meddelanden.
4. **Mobilmeny** – en responsiv navigeringsmeny som kan öppnas och stängas.

## Responsiv design och tillgänglighet

Webbplatsen är anpassad för mobil, surfplatta och dator med CSS Grid, Flexbox och media queries.

Jag har även arbetat med semantisk HTML, tangentbordsnavigering, tydliga fokusmarkeringar och en länk för att hoppa direkt till innehållet.
