Om mig

Jag heter Feroza Darwish och studerar till systemutvecklare .NET samtidigt som jag arbetar som bemanningsplanerare.

I min nuvarande roll som bemanningsplanerare arbetar jag med planering, administration och problemlösning. Arbetet har utvecklat min organisationsförmåga, mitt ansvarstagande och min förmåga att samarbeta med andra.

Mitt stora intresse för teknik och programmering har inspirerat mig att vidareutbilda mig inom IT. Jag vill kombinera min tidigare arbetslivserfarenhet med nya tekniska kunskaper.

Under min utbildning arbetar jag med bland annat C#, .NET, HTML, CSS, JavaScript och React. Jag tycker om att lära mig nya saker, lösa problem och utvecklas genom praktiska projekt.

Mina projekt

Här presenterar jag några av de projekt jag har arbetat med under min utbildning.

Bibliotekssystem

Ett bibliotekssystem utvecklat med C#, .NET och Avalonia UI. Projektet handlar om att hantera böcker och utlåning genom ett grafiskt användargränssnitt.

Tekniker: C#, .NET, Avalonia UI

TicTacToeGUI – Tre i rad

Ett grafiskt spel där två spelare turas om att placera X och O. Spelet kontrollerar vinnare, oavgjort och har möjlighet att startas om.

Tekniker: C#, .NET, Avalonia UI

Ett grupparbete där vi utvecklade ett system för lagerhantering. Jag ansvarade för inloggningsfunktionen med mock-data och kopplade den till Dashboard med hjälp av React Router.

Tekniker: React, JavaScript, CSS
